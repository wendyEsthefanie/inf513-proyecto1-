# Ejecutar en Windows

1. Instale Java 17 o superior para Windows y compruebe `java -version`.
2. Extraiga completamente este ZIP.
3. Abra la carpeta correo_academia_22sc y haga doble clic en INICIAR.cmd.

El programa ya está compilado e incluye sus bibliotecas y configuración remota. No requiere Maven, VS Code, PostgreSQL local ni recompilar. Necesita conexión a Internet para correo y base de datos. Mantenga abierta la ventana mientras funcione; Ctrl+C lo detiene. No ejecute otro receptor de la misma cuenta simultáneamente.

Este paquete contiene credenciales privadas: no lo publique.

El paquete se verificó estructuralmente en Linux; no se ejecutó en Windows durante esta preparación.
